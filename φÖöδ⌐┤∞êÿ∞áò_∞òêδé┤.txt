첫사랑 뮤지컬 앱 화면 수정 안내

1. 상단에 CSS 코드가 텍스트로 노출되던 오류를 수정했습니다.
2. 탭 메뉴 8개(초대장, 포스터, 기획의도, 시놉시스, 출연진, 스태프, 응원메시지, 후기)를 공연 제목·일시·장소 바로 아래 4개씩 2줄로 배치했습니다.
3. 모바일 하단 고정 탭 메뉴를 제거했습니다.
4. 상단 타이틀 영역의 패딩과 간격을 줄였습니다.
5. 음악 재생 컨트롤은 하단 우측에 표시하고, 기본 탭 메뉴와 겹치지 않도록 위치를 조정했습니다.
6. 기존 Supabase 연결, 응원메시지, 후기 개방 시간, 개막 축하 애니메이션, 음원 파일을 유지했습니다.

배포: 압축을 해제하여 파일 전체를 GitHub MUSICAl 저장소 최상위에 덮어쓰세요. 특히 index.html과 firstlove-bgm.mp3는 반드시 함께 업로드해야 합니다.
업데이트 후 iPhone Safari에서는 새로고침 또는 홈 화면 앱 종료 후 재실행을 권장합니다.
