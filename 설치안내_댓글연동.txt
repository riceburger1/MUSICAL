첫사랑 뮤지컬 앱 - 온라인 댓글 연동 적용본

1. SQL Editor에서 public.firstlove_messages 생성 및 RLS 정책 적용 완료 상태여야 합니다.
2. config.js에는 사용자가 제공한 전용 프로젝트 URL과 공개 Publishable key가 반영되어 있습니다.
3. GitHub Pages 저장소의 웹 최상위 폴더에 index.html, config.js, 이미지, 아이콘, manifest.webmanifest 파일을 모두 업로드(기존 파일 덮어쓰기)하세요.
4. 웹사이트를 열고 응원메시지 탭에서 '온라인 연결됨' 안내가 나오는지 확인하세요.
5. PC에서 시험 댓글을 하나 등록한 후 다른 휴대폰이나 브라우저에서 같은 글이 표시되는지 확인하세요.
6. 후기 탭은 2026-11-22 14:30 한국시간부터 쓰기 가능합니다.
7. 댓글이 표시되지 않으면 브라우저 캐시를 강제 새로고침하고 config.js 파일이 GitHub에 올라갔는지 확인하세요.

주의:
- 기존 localStorage에 저장된 글은 자동으로 서버로 이동하지 않습니다.
- 관리자 인증 없는 공개 댓글판이므로 스팸, 부적절한 글 삭제를 위한 관리 절차를 마련하세요.
- Publishable key는 공개용이며 Secret/service_role 키는 절대로 웹에 업로드하지 마세요.
- 이번 결과물은 파일 수준 연결 설정이며 실제 Supabase 네트워크에 대한 저장/조회 성공 테스트는 별도로 확인해야 합니다.
